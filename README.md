## ✨ 功能特色

- **公式速查庫**：弧度制、圖形伸縮、和差倍半角、疊合公式一覽
- **解題題型對照矩陣**：題目關鍵字 → 核心公式 → SOP → 避坑提醒
- **十大解題 SOP**：從弧度判斷到正餘弦疊合，附例題演示
- **避坑指南**：歷屆學測易錯地雷逐一解說
- **7 份進階試題逐題解析**：每題附核心講義頁碼對照
- **MathJax 數學渲染**：所有公式清晰顯示
- **深色/淺色模式切換**
- **列印友好版面**：每大主題單獨一頁
