單一選擇題（共 8 題）

第 1 題：最接近 1 的數值估算
名校考題
下列哪一個數值最接近 $1$？
(A) $\sin 28^\circ + \sqrt{3}\cos 28^\circ$
(B) $\sin 48^\circ + \sqrt{3}\cos 48^\circ$
(C) $\sin 68^\circ + \sqrt{3}\cos 68^\circ$
(D) $\sin 88^\circ + \sqrt{3}\cos 88^\circ$
(E) $\sin 108^\circ + \sqrt{3}\cos 108^\circ$
標準答案： (D)
💡 完整解析：
由正餘弦疊合標準式：$\sin\theta + \sqrt{3}\cos\theta = 2\left(\frac{1}{2}\sin\theta + \frac{\sqrt{3}}{2}\cos\theta\right) = 2\sin(\theta + 60^\circ)$。
• (A) $2\sin(28^\circ + 60^\circ) = 2\sin 88^\circ$
• (B) $2\sin(48^\circ + 60^\circ) = 2\sin 108^\circ = 2\sin 72^\circ$
• (C) $2\sin(68^\circ + 60^\circ) = 2\sin 128^\circ = 2\sin 52^\circ$
• (D) $2\sin(88^\circ + 60^\circ) = 2\sin 148^\circ = 2\sin 32^\circ$
• (E) $2\sin(108^\circ + 60^\circ) = 2\sin 168^\circ = 2\sin 12^\circ$
因為目標值 $1 = 2\sin 30^\circ$，而在所有選項中 $2\sin 32^\circ$ 與 $2\sin 30^\circ = 1$ 最接近，故選 (D)。
本題用到講義的哪些模組？
第 1 頁：1-4 正餘弦疊合標準式 第 2 頁：無單位/特殊角三角比數值對照 第 3 頁：SOP 1 單位圓角度與投影法
解題關鍵對照：利用 1-4 正餘弦疊合將 $\sin\theta+\sqrt{3}\cos\theta$ 轉為 $2\sin(\theta+60^\circ)$，再將目標常數 $1$ 逆向化為 $2\sin 30^\circ$，即可一眼比對角度差距！
第 2 題：分式和差化簡求值
臺南女中
$\frac{1}{\sin 50^\circ} + \frac{\sqrt{3}}{\cos 50^\circ}$ 的值為下列何者？
(A) $4$
(B) $2$
(C) $\frac{\sqrt{3}}{2}$
(D) $-1$
(E) $-4$
標準答案： (A)
💡 完整解析：
1. 通分：$\frac{1}{\sin 50^\circ} + \frac{\sqrt{3}}{\cos 50^\circ} = \frac{\cos 50^\circ + \sqrt{3}\sin 50^\circ}{\sin 50^\circ \cos 50^\circ}$。
2. 分子正餘弦疊合：$\cos 50^\circ + \sqrt{3}\sin 50^\circ = 2\left(\frac{\sqrt{3}}{2}\sin 50^\circ + \frac{1}{2}\cos 50^\circ\right) = 2\sin(50^\circ + 30^\circ) = 2\sin 80^\circ$。
3. 分母利用二倍角公式：$\sin 50^\circ \cos 50^\circ = \frac{1}{2}\sin 100^\circ = \frac{1}{2}\sin(180^\circ - 80^\circ) = \frac{1}{2}\sin 80^\circ$。
4. 相除：$\frac{2\sin 80^\circ}{\frac{1}{2}\sin 80^\circ} = 4$。故選 (A)。
本題用到講義的哪些模組？
第 1 頁：1-3 二倍角公式 $\sin 2\theta = 2\sin\theta\cos\theta$ 第 1 頁：1-4 正餘弦疊合標準式 第 2 頁：和角拆角與二倍角連鎖對照
解題關鍵對照：分子使用 1-4 疊合化為 $2\sin 80^\circ$，分母使用 1-3 二倍角逆用化為 $\frac{1}{2}\sin 100^\circ = \frac{1}{2}\sin 80^\circ$，上下消去獲解。
第 3 題：疊合函數求最大值
興大附中
下列選項中的值何者最大？
(A) $\sin 10^\circ + \sqrt{3}\cos 10^\circ$
(B) $\sin 20^\circ + \sqrt{3}\cos 20^\circ$
(C) $\sin 30^\circ + \sqrt{3}\cos 30^\circ$
(D) $\sin 40^\circ + \sqrt{3}\cos 40^\circ$
(E) $\sin 50^\circ + \sqrt{3}\cos 50^\circ$
標準答案： (C)
💡 完整解析：
原式疊合為 $2\sin(\theta + 60^\circ)$。
當 $\theta = 30^\circ$ 時，$2\sin(30^\circ + 60^\circ) = 2\sin 90^\circ = 2$ 達到正弦函數之最大波峰值 $2$，其餘選項皆小於 $2$。故選 (C)。
本題用到講義的哪些模組？
第 1 頁：1-4 正餘弦疊合與極值 第 3 頁：SOP 8 受限區間疊合極值判定
解題關鍵對照：疊合為 $2\sin(\theta+60^\circ)$ 後，直接尋找能使複合角等於波峰角 $90^\circ$ 的選項。
第 4 題：分式型三角函數求極值
臺中二中
設 $y = \frac{2}{3\sin\theta - 4\cos\theta + 7}$，則 $y$ 之最大值為？
(A) $\frac{1}{6}$
(B) $\frac{1}{2}$
(C) $1$
(D) $\frac{3}{2}$
(E) $2$
標準答案： (C)
💡 完整解析：
1. 分母部分疊合：$-\sqrt{3^2+(-4)^2} \le 3\sin\theta - 4\cos\theta \le \sqrt{3^2+(-4)^2} \implies -5 \le 3\sin\theta - 4\cos\theta \le 5$。
2. 加常數 7：$2 \le 3\sin\theta - 4\cos\theta + 7 \le 12$。
3. 取倒數乘 2：欲使 $y$ 最大，分母須取最小值 $2$，$y_{\max} = \frac{2}{2} = 1$。故選 (C)。
本題用到講義的哪些模組？
第 1 頁：1-4 正餘弦疊合極值範圍 $[-\sqrt{a^2+b^2}, \sqrt{a^2+b^2}]$ 第 2 頁：疊合極值對照矩陣
解題關鍵對照：先求分母 $3\sin\theta-4\cos\theta$ 的振幅範圍 $[-5, 5]$，分式取最大值對應分母取最小值。
第 5 題：求最大值發生的 $x$ 自變數
臺南女中
函數 $f(x) = \sin x + \sqrt{3}\cos x + 2$ 在以下哪個 $x$ 值時有最大值？
(A) $\frac{\pi}{6}$
(B) $\frac{\pi}{3}$
(C) $\frac{\pi}{2}$
(D) $\frac{2\pi}{3}$
(E) $\frac{5\pi}{6}$
標準答案： (A)
💡 完整解析：
$f(x) = 2\left(\frac{1}{2}\sin x + \frac{\sqrt{3}}{2}\cos x\right) + 2 = 2\sin(x + \frac{\pi}{3}) + 2$。
當正弦達波峰時：$x + \frac{\pi}{3} = \frac{\pi}{2} \implies x = \frac{\pi}{2} - \frac{\pi}{3} = \frac{\pi}{6}$。故選 (A)。
本題用到講義的哪些模組？
第 1 頁：1-4 正餘弦疊合標準式 第 3 頁：SOP 8 有限區間求疊合極值波峰反解
解題關鍵對照：疊合後令複合角 $x+\frac{\pi}{3} = \frac{\pi}{2}$，快速移項求得 $x = \frac{\pi}{6}$。
第 6 題：最接近 $\sqrt{2}$ 的角度比較
嘉義女中
選出值最接近 $\sqrt{2}$ 的選項：
(A) $\sin 44^\circ + \sqrt{3}\cos 44^\circ$
(B) $\sin 54^\circ + \sqrt{3}\cos 54^\circ$
(C) $\sin 64^\circ + \sqrt{3}\cos 64^\circ$
(D) $\sin 74^\circ + \sqrt{3}\cos 74^\circ$
(E) $\sin 84^\circ + \sqrt{3}\cos 84^\circ$
標準答案： (D)
💡 完整解析：
所有選項均可疊合為 $2\sin(\theta + 60^\circ)$。
• (A) $2\sin 104^\circ = 2\sin 76^\circ$
• (B) $2\sin 114^\circ = 2\sin 66^\circ$
• (C) $2\sin 124^\circ = 2\sin 56^\circ$
• (D) $2\sin 134^\circ = 2\sin 46^\circ$
• (E) $2\sin 144^\circ = 2\sin 36^\circ$
目標值 $\sqrt{2} = 2 \times \frac{\sqrt{2}}{2} = 2\sin 45^\circ$，與 $2\sin 46^\circ$ 最接近。故選 (D)。
本題用到講義的哪些模組？
第 1 頁：1-4 正餘弦疊合標準式 第 4 頁：特殊角數值速查表（$\sin 45^\circ = \frac{\sqrt{2}}{2}$）
解題關鍵對照：疊合為 $2\sin(\theta+60^\circ)$ 後，結合第 4 頁特殊角表將 $\sqrt{2}$ 改寫為 $2\sin 45^\circ$ 進行鄰近度比對。
第 7 題：三角方程式解的存在性判定
臺南女中
設 $x$ 為實數，則下列哪個方程式有解？
(A) $\sin x + \cos x = 2$
(B) $\sin x \cos x = 1$
(C) $\sin x + \frac{1}{\sin x} = 1$
(D) $2\sin x + 3\cos x = 4$
(E) $3\sin x + 4\cos x = 5$
標準答案： (E)
💡 完整解析：
• (A) $\sin x + \cos x = \sqrt{2}\sin(x+\frac{\pi}{4}) \in [-\sqrt{2}, \sqrt{2}]$，因 $2 > \sqrt{2}$，無解。
• (B) $\sin x\cos x = \frac{1}{2}\sin 2x \le \frac{1}{2} < 1$，無解。
• (C) 同乘 $\sin x$ 得 $\sin^2 x - \sin x + 1 = 0$，判別式 $D = (-1)^2 - 4(1)(1) = -3 < 0$，無實數解。
• (D) $2\sin x + 3\cos x \in [-\sqrt{13}, \sqrt{13}]$，因 $\sqrt{13} \approx 3.6 < 4$，無解。
• (E) $3\sin x + 4\cos x = 5\sin(x+\phi) \in [-5, 5]$，常數 $5$ 恰在值域上界，有實數解。故選 (E)。
本題用到講義的哪些模組？
第 1 頁：1-4 疊合極值範圍 $[-\sqrt{a^2+b^2}, \sqrt{a^2+b^2}]$ 第 1 頁：1-3 二倍角公式 $\sin 2x = 2\sin x\cos x$ 第 3 頁：SOP 5 方程式實根數形邊界分析
解題關鍵對照：利用疊合振幅值域上下界判斷常數是否落在區間內，(E) 選項 $3^2+4^2 = 5^2$，極大值恰好為 5。
第 8 題：受限區間疊合極值之和
師大附中
函數 $f(x) = -\sin x + \sqrt{3}\cos x + 2$ 在 $\frac{2\pi}{3} \le x \le \frac{13\pi}{12}$ 的最大值為 $M$，最小值為 $N$，求 $M + N = $？
(A) $4$
(B) $0$
(C) $-\sqrt{2}$
(D) $2 - \sqrt{2}$
(E) $2 - \sqrt{3}$
標準答案： (D)
💡 完整解析：
1. 疊合：$f(x) = 2\left(-\frac{1}{2}\sin x + \frac{\sqrt{3}}{2}\cos x\right) + 2 = 2\sin(x + \frac{2\pi}{3}) + 2$。
2. 換元：令 $\theta = x + \frac{2\pi}{3}$。因 $\frac{2\pi}{3} \le x \le \frac{13\pi}{12}$，故 $\frac{4\pi}{3} \le \theta \le \frac{7\pi}{4}$。
3. 單位圓檢驗：此區間涵蓋波谷角 $\frac{3\pi}{2}$，故 $\sin\theta$ 最小值為 $-1 \implies N = 2(-1) + 2 = 0$。
4. 端點最大值：在 $\theta = \frac{7\pi}{4}$ 時，$\sin\frac{7\pi}{4} = -\frac{\sqrt{2}}{2}$，故 $M = 2\left(-\frac{\sqrt{2}}{2}\right) + 2 = 2 - \sqrt{2}$。
5. $M + N = (2 - \sqrt{2}) + 0 = 2 - \sqrt{2}$。故選 (D)。
本題用到講義的哪些模組？
第 1 頁：1-4 正餘弦疊合與輔助角象限 第 3 頁：SOP 8 有限區間求疊合極值三步驟 第 4 頁：避坑口訣 4「受限區間極值勿只代端點」
解題關鍵對照：嚴格遵守 SOP 8 換元推導 $\theta \in [\frac{4\pi}{3}, \frac{7\pi}{4}]$，檢驗出涵蓋波谷 $\frac{3\pi}{2}$ 得最小值 0，端點得最大值 $2-\sqrt{2}$。
二、多選題

多重選擇題（共 7 題）

多選 1：函數性質與受限區間極值
臺南女中
關於函數 $f(x) = 4\sin x - 3\cos x$，請選出正確的選項：
(A) $f(x)$ 的週期為 $2\pi$
(B) $f(x)$ 的振幅為 $5$
(C) 若 $x$ 為任意實數，則 $f(x)$ 的最小值為 $-5$
(D) 若 $0 \le x \le \pi$，則 $f(x)$ 的最小值為 $-5$
(E) 若 $0 \le x \le \frac{\pi}{2}$，則 $f(x)$ 的最小值為 $-5$
標準答案： (A)(B)(C)
💡 完整解析：
疊合 $f(x) = 5\sin(x - \theta)$，其中 $\cos\theta = \frac{4}{5}, \sin\theta = \frac{3}{5}$（$\theta \approx 37^\circ$ 為第一象限角）。
• (A) 週期 $T = 2\pi$。(正確)
• (B) 振幅 $R = \sqrt{4^2+(-3)^2} = 5$。(正確)
• (C) 全實數最小值為 $-5$。(正確)
• (D)(E) 當 $0 \le x \le \pi$ 時，$-\theta \le x - \theta \le \pi - \theta$。此區間不包含波谷角 $-\frac{\pi}{2}$（或 $\frac{3\pi}{2}$），故最小值發生在端點 $x=0$，值為 $5\sin(-\theta) = -5\sin\theta = -3$（非 $-5$）。(D)(E均錯誤)
故選 (A)(B)(C)。
本題用到講義的哪些模組？
第 1 頁：1-2 振幅與週期、1-4 正餘弦疊合 第 3 頁：SOP 8 有限區間疊合極值 第 4 頁：避坑口訣 4「換元檢查波谷是否在區間內」
解題關鍵對照：疊合為 $5\sin(x-\theta)$，由於 $\theta \approx 37^\circ$，在 $[0, \pi]$ 換元後 $[-\theta, \pi-\theta]$ 未覆蓋 $-90^\circ$，因此最小值只能取到 $-3$ 而非 $-5$。
多選 2：對稱軸、實根數、多根和與平移
臺中一中・經典大考題
令 $f(x) = \sin x - \sqrt{3}\cos x$，試選出正確的選項：
(A) 鉛直線 $x = \frac{5\pi}{6}$ 為 $y = f(x)$ 圖形的對稱軸
(B) 若鉛直線 $x=a$ 與 $x=b$ 均為對稱軸，則 $f(a) = f(b)$
(C) 在區間 $[0, 2\pi)$ 中恰有兩個相異實數滿足 $f(x) = \sqrt{3}$
(D) 在區間 $[0, 2\pi)$ 中滿足 $f(x) = \frac{1}{2}$ 的所有實數之和不超過 $2\pi$
(E) $y = f(x)$ 的圖形可由 $y = 4\sin^2\frac{x}{2}$ 經平移得到
標準答案： (A)(C)(D)(E)
💡 完整解析：
疊合 $f(x) = 2\sin(x - \frac{\pi}{3})$。
• (A) $f(\frac{5\pi}{6}) = 2\sin(\frac{5\pi}{6} - \frac{\pi}{3}) = 2\sin\frac{\pi}{2} = 2$ 為波峰，故為對稱軸。(正確)
• (B) 對稱軸可能在波峰（值為 $2$）或波谷（值為 $-2$），兩者值不一定相等。(錯誤)
• (C) $2\sin(x - \frac{\pi}{3}) = \sqrt{3} \implies \sin(x - \frac{\pi}{3}) = \frac{\sqrt{3}}{2}$，在一週期內恰有 2 根。(正確)
• (D) $f(p)=f(q)=\frac{1}{2}$，兩根對稱於波峰對稱軸 $x = \frac{5\pi}{6}$，由中點對稱性 $p+q = 2 \times \frac{5\pi}{6} = \frac{5\pi}{3} < 2\pi$。(正確)
• (E) 降次公式 $4\sin^2\frac{x}{2} = 4\left(\frac{1-\cos x}{2}\right) = 2 - 2\cos x = 2\sin(x - \frac{\pi}{2}) + 2$，振幅與週期與 $f(x)$ 相同，可由平移得到。(正確)
故選 (A)(C)(D)(E)。
本題用到講義的哪些模組？
第 1 頁：1-3 半角降次公式 $2\sin^2\frac{x}{2} = 1-\cos x$ 第 3 頁：SOP 5 方程式交點個數分析 第 3 頁：SOP 6 對稱性求多根總和（$p+q = 2x_0$）
解題關鍵對照：(D) 選項完美體現了講義 SOP 6「利用波峰對稱軸快速求兩根之和 $2 \times \frac{5\pi}{6} = \frac{5\pi}{3}$」；(E) 選項使用第 1 頁降次公式轉化。
多選 3：四個象限區間極值深度辨析
興大附中
關於函數 $f(x) = 4\sin x - 3\cos x$，請選出正確的選項：
(A) $f(x)$ 的週期為 $2\pi$
(B) $f(x)$ 的振幅為 $5$
(C) 若 $0 \le x \le \frac{\pi}{2}$，則 $f(x)$ 的最小值為 $3$
(D) 若 $\frac{\pi}{2} \le x \le \pi$，則 $f(x)$ 的最小值為 $4$
(E) 若 $\pi \le x \le \frac{3\pi}{2}$，則 $f(x)$ 的最小值為 $-4$
標準答案： (A)(B)(E)
💡 完整解析：
疊合 $f(x) = 5\sin(x - \theta)$，其中 $\cos\theta = \frac{4}{5}, \sin\theta = \frac{3}{5}$。
• (A)(B) 週期 $2\pi$、振幅 $5$。(正確)
• (C) $0 \le x \le \frac{\pi}{2} \implies -\theta \le x - \theta \le \frac{\pi}{2} - \theta$。最小值在 $x=0$ 為 $5\sin(-\theta) = -3$。(錯誤)
• (D) $\frac{\pi}{2} \le x \le \pi \implies \frac{\pi}{2}-\theta \le x-\theta \le \pi-\theta$。最小值在 $x=\pi$ 為 $5\sin(\pi-\theta) = 5\sin\theta = 3$。(錯誤)
• (E) $\pi \le x \le \frac{3\pi}{2} \implies \pi-\theta \le x-\theta \le \frac{3\pi}{2}-\theta$。最小值在 $x=\frac{3\pi}{2}$ 為 $5\sin(\frac{3\pi}{2}-\theta) = -5\cos\theta = -4$。(正確)
故選 (A)(B)(E)。
本題用到講義的哪些模組？
第 1 頁：1-4 疊合輔助角誘導公式 第 3 頁：SOP 8 有限區間疊合極值
解題關鍵對照：利用換元法將每個象限端點代入 $\sin(\frac{3\pi}{2}-\theta) = -\cos\theta$，再結合 $\cos\theta = \frac{4}{5}$ 算出精確值 $-4$。
多選 4：和角展開、疊合與圖形單調性
臺南女中
關於函數 $y = f(x) = 2\cos(x - \frac{\pi}{3}) - 2\cos x$，請問下列各敘述何者為真？
(A) 函數 $y = f(x)$ 的週期為 $2\pi$
(B) 函數 $y = f(x)$ 的最大值為 $1$
(C) $f(3) > 0$
(D) 在 $\frac{\pi}{2} \le x \le \pi$ 時，圖形為遞減
標準答案： (A)(C)
💡 完整解析：
1. 展開化簡：$2\cos(x - \frac{\pi}{3}) - 2\cos x = 2(\cos x\cos\frac{\pi}{3} + \sin x\sin\frac{\pi}{3}) - 2\cos x = \cos x + \sqrt{3}\sin x - 2\cos x = \sqrt{3}\sin x - \cos x$。
2. 疊合：$\sqrt{3}\sin x - \cos x = 2\sin(x - \frac{\pi}{6})$。
• (A) 週期為 $2\pi$。(正確)
• (B) 最大值為 $2$（非 $1$）。(錯誤)
• (C) $x = 3 \text{ rad} \approx 171.9^\circ$，$3 - \frac{\pi}{6} \approx 171.9^\circ - 30^\circ = 141.9^\circ$ 在第二象限，正弦值為正，故 $f(3) > 0$。(正確)
• (D) 在 $\frac{\pi}{2} \le x \le \frac{2\pi}{3}$ 遞增，$\frac{2\pi}{3} \le x \le \pi$ 遞減，並非全程遞減。(錯誤)
故選 (A)(C)。

計算 3：扇形內接矩形最大面積
臺中一中・經典名題
扇形 $OAB$ 圓心角 $\angle AOB = \frac{\pi}{4} = 45^\circ$，半徑 $OA = OB = 1$。四邊形 $PQRS$ 為扇形之內接矩形（$P, Q$ 在半徑上，$R, S$ 在弧與對邊上），令 $\angle SOR = \theta$：
(1) 試以 $\theta$ 表示矩形 $PQRS$ 的面積。
(2) 求矩形 $PQRS$ 面積之最大值。
標準答案： (1) $\sin\theta(\cos\theta - \sin\theta)$；(2) 最大值 $\frac{\sqrt{2}-1}{2}$
💡 完整解析：
1. 邊長設定：在直角 $\triangle OSR$ 中，$OR = 1$，$RS = \sin\theta, \quad OS = \cos\theta$。
因 $\angle AOB = 45^\circ$，頂點 $Q$ 處為等腰直角三角形 $\implies OQ = RS = \sin\theta$。
故矩形長度 $QR = OS - OQ = \cos\theta - \sin\theta$。
2. 面積函數：
$A(\theta) = RS \times QR = \sin\theta(\cos\theta - \sin\theta) = \sin\theta\cos\theta - \sin^2\theta$。
3. 倍角與降次轉化：
$A(\theta) = \frac{1}{2}\sin 2\theta - \frac{1-\cos 2\theta}{2} = \frac{1}{2}\sin 2\theta + \frac{1}{2}\cos 2\theta - \frac{1}{2}$。
4. 疊合：
$\frac{1}{2}\sin 2\theta + \frac{1}{2}\cos 2\theta = \frac{\sqrt{2}}{2}\sin(2\theta + \frac{\pi}{4})$。
故最大面積為 $\frac{\sqrt{2}}{2}(1) - \frac{1}{2} = \frac{\sqrt{2}-1}{2}$。
本題用到講義的哪些模組？
第 1 頁：1-3 二倍角與降次公式 第 1 頁：1-4 正餘弦疊合標準式 第 3 頁：SOP 8 疊合極值標準程序
解題關鍵對照：邊長表達為 $\sin\theta(\cos\theta-\sin\theta)$ 後，利用 1-3 降次與倍角轉化為 $\frac{1}{2}\sin 2\theta + \frac{1}{2}\cos 2\theta - \frac{1}{2}$，再疊合求出最大值 $\frac{\sqrt{2}-1}{2}$。
