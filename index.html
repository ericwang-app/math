108 課綱 數學 A/B・大考衝刺必備【第 1 頁】

Ch1 三角函數 全章必備核心公式庫 (Formula Sheet)

四大單元公式速查：弧度扇形、圖形伸縮平移、和差倍半角、正餘弦疊合

1-1 弧度制、扇形幾何與極值
$$1\text{ rad} = \left(\frac{180}{\pi}\right)^\circ \approx 57.3^\circ, \quad s = r\theta, \quad A = \frac{1}{2}r^2\theta = \frac{1}{2}rs$$
  • 周長固定之最大面積定理： 扇形周長 $L = 2r + s$ 固定時，當 $\theta = 2\text{ rad}$ 時面積最大：$A_{\max} = \frac{L^2}{16}$。
  • 弓形面積： $A_{\text{弓}} = \frac{1}{2}r^2(\theta - \sin\theta)$（$\theta$ 須為弧度）。
  • 同界角通式： $\theta_1 - \theta_2 = 2k\pi \quad (k \in \mathbb{Z})$。
  • 滾動距離公式： 輪子滾動距離 $d = r\theta$；離地高度 $h = r - r\cos\theta$。
1-2 函數圖形伸縮平移與絕對值
$$y = a\sin\left[b\left(x - \frac{c}{b}\right)\right] + d$$
  • 振幅與極值： 振幅 $|a|$，最大值 $d+|a|$，最小值 $d-|a|$，平衡線 $y = d$。
  • 週期 $T$： 正弦/餘弦 $T = \frac{2\pi}{|b|}$，正切 $T = \frac{\pi}{|b|}$。
  • 水平平移量： 向右平移 $\frac{c}{b}$ 單位（必先將 $b$ 提出！）。
  • 對稱軸： $\sin$ 在波峰/波谷 $x = \frac{\pi}{2}+k\pi$；$\cos$ 在 $x = k\pi$。
  • 絕對值圖形： $y = |\sin x|$ 週期減半為 $\pi$；$y = \sin|x|$ 為偶函數。
1-3 和差角、平方差、倍角與三倍角
$$\sin(\alpha \pm \beta) = \sin\alpha\cos\beta \pm \cos\alpha\sin\beta$$ $$\cos(\alpha \pm \beta) = \cos\alpha\cos\beta \mp \sin\alpha\sin\beta$$ $$\tan(\alpha \pm \beta) = \frac{\tan\alpha \pm \tan\beta}{1 \mp \tan\alpha\tan\beta}, \quad \tan\theta = \left|\frac{m_1 - m_2}{1 + m_1 m_2}\right|$$
  • 正餘弦平方差： $\sin(\alpha+\beta)\sin(\alpha-\beta) = \sin^2\alpha - \sin^2\beta$。
  • 二倍角與降次： $\sin 2\theta = 2\sin\theta\cos\theta, \quad \cos 2\theta = 2\cos^2\theta - 1 = 1 - 2\sin^2\theta$。
  • 三倍角公式： $\sin 3\theta = 3\sin\theta - 4\sin^3\theta, \quad \cos 3\theta = 4\cos^3\theta - 3\cos\theta$。
  • 半角公式： $\sin\frac{\theta}{2} = \pm\sqrt{\frac{1-\cos\theta}{2}}, \quad \cos\frac{\theta}{2} = \pm\sqrt{\frac{1+\cos\theta}{2}}$。
1-4 正餘弦疊合與極值判定
$$a\sin x + b\cos x = \sqrt{a^2+b^2}\sin(x + \phi)$$ $$\text{其中 } \cos\phi = \frac{a}{\sqrt{a^2+b^2}}, \quad \sin\phi = \frac{b}{\sqrt{a^2+b^2}}$$
  • 無限制範圍極值： $-\sqrt{a^2+b^2} \le y \le \sqrt{a^2+b^2}$，疊合後週期為 $2\pi$。
  • 輔助角象限判定： 輔助角 $\phi$ 所在的象限由坐標點 $(a, b)$ 正負決定。
  • 受限區間極值SOP： 換元 $\theta = x+\phi$，依單位圓檢查是否包含 $\frac{\pi}{2}$ 或 $\frac{3\pi}{2}$。
  • 二次複合極值： $y = a\cos^2 x + b\sin x + c \implies$ 令 $t = \sin x \in [-1, 1]$ 配方。
PART 2

解題題型 ↔ 核心技巧對照矩陣【第 2 頁】

題目關鍵字 / 題型特徵 對應核心公式 標準解題步驟 (SOP) 避坑提醒
無單位三角比比大小
($\sin 1, \sin 2, \cos 1, \tan 1$)		 $1\text{ rad} \approx 57.3^\circ$
單位圓坐標 $(\cos\theta, \sin\theta)$		 1. 換算弧度為大致度數。
2. 正弦看高度、餘弦看橫寬、正切看斜率。
3. 在單位圓上標出投影比大小。		 無度數符號為弧度（$\cos 10 \ne \cos 10^\circ$）。
扇形周長固定求最大面積
(鐵絲圍扇形、最大面積)		 $L = 2r + r\theta$
$A = \frac{1}{2}r^2\theta = \frac{1}{2}r(L-2r)$		 1. 建立面積二次函數 $A = -\left(r-\frac{L}{4}\right)^2 + \frac{L^2}{16}$。
2. 當半徑 $r = \frac{L}{4}$（即圓心角 $\theta = 2\text{ rad}$）時，面積最大值 $A_{\max} = \frac{L^2}{16}$。		 圓心角必為 $2\text{ 弧度}$（約 $114.6^\circ$）。
幾何滾動 / 鐘錶指針
(輪胎滾動高度、指針夾角)		 $d = r\theta$
$h = r - r\cos\theta$
分針 $\frac{\pi}{30}\text{ rad/分}$，時針 $\frac{\pi}{360}\text{ rad/分}$		 1. 滾動直線距離 $=$ 輪緣滾過弧長 $d = r\theta$。
2. 旋轉角 $\theta = \frac{d}{r}$。
3. 利用圓心直角三角形求離地高度。		 轉動角 $\theta$ 超過 $\pi$ 時注意高低差符號。
圖形平移伸縮變換
($y = a\sin(bx-c)+d$)		 $y = a\sin\left[b\left(x - \frac{c}{b}\right)\right] + d$ 1. 先將 $x$ 的係數 $b$ 提出括號。
2. 水平向右平移量為 $\frac{c}{b}$。
3. 振幅為 $|a|$，週期為 $\frac{2\pi}{|b|}$。		 勿直接視 $c$ 為平移量（必為 $\frac{c}{b}$）。
方程式實根個數 / 交點
($\sin x = \frac{x}{3\pi}$, $\sin 2x = \cos 2x$)		 數形結合：$\begin{cases} y_1 = \sin x \\ y_2 = g(x) \end{cases}$ 1. 找出直線達振幅邊界 $\pm 1$ 的範圍。
2. 超出範圍必無交點。
3. 在有效區間標出零點與波峰數交點。		 注意題目給定的 $x$ 區間限制（如 $[0, 2\pi]$）。
對稱軸與多根總和
(求 $\sin x = k$ 在 $[0, 2\pi]$ 根之和)		 $\sin$ 對稱軸 $x = \frac{\pi}{2}, \frac{3\pi}{2}$
$\cos$ 對稱軸 $x = \pi$		 1. 找出兩對稱根的中點對稱軸 $x = x_0$。
2. 兩根之和直接等於 $2x_0$。
3. 無需算出個別未知角度值。		 檢查根是否存在於指定區間內。
給定 $\sin\theta \pm \cos\theta = k$
(求 $\sin 2\theta, \tan\theta$)		 $(\sin\theta \pm \cos\theta)^2 = 1 \pm \sin 2\theta$
$\tan\theta + \frac{1}{\tan\theta} = \frac{2}{\sin 2\theta}$		 1. 兩邊平方求出 $\sin 2\theta = k^2 - 1$。
2. 相乘 $\sin\theta\cos\theta = \frac{k^2-1}{2}$。
3. 相減開方 $(\sin\theta-\cos\theta)^2 = 2-k^2$。		 開方時須依 $\theta$ 象限判斷正負。
三倍角與立方化簡
(化簡 $\sin 3\theta, \cos 3\theta$)		 $\sin 3\theta = 3\sin\theta - 4\sin^3\theta$
$\cos 3\theta = 4\cos^3\theta - 3\cos\theta$		 1. 遇到 $\sin^3\theta$ 移項為 $\frac{3\sin\theta - \sin 3\theta}{4}$ 降次。
2. 代入特殊角（如 $\theta = 10^\circ, 20^\circ$）求值。		 口訣：3 仙 - 4 仙草；4 塊 - 3 塊錢。
受限區間疊合極值
($f(x) = a\sin x + b\cos x, x \in [\alpha, \beta]$)		 $f(x) = \sqrt{a^2+b^2}\sin(x + \phi)$ 1. 疊合為 $r\sin(x+\phi)$。
2. 換元推導複合角 $\theta = x+\phi$ 的範圍。
3. 檢驗是否涵蓋波峰 $\frac{\pi}{2}$ 或波谷 $\frac{3\pi}{2}$。		 勿盲目只代左右端點！
幾何求角 / 兩線夾角
(正方形拼接求角、兩直線夾角)		 $\tan(\alpha \pm \beta) = \frac{\tan\alpha \pm \tan\beta}{1 \mp \tan\alpha\tan\beta}$
$\tan\theta = \left|\frac{m_1 - m_2}{1 + m_1 m_2}\right|$		 1. 將未知角拆解為直角三角形兩角之差 $\alpha-\beta$。
2. 讀取 $\tan\alpha, \tan\beta$。
3. 代入正切差角公式求值。		 求銳夾角必須加絕對值。
PART 3

十大解題技巧標準作業程序 (Problem-Solving SOPs)【第 3 頁】

SOP 1：無單位三角比大小排序 單元 1-1
步驟 1：轉化實數弧度為近似角度：
$1 \approx 57.3^\circ$ (I), $2 \approx 114.6^\circ$ (II), $3 \approx 171.9^\circ$ (II末), $4 \approx 229.2^\circ$ (III)。
步驟 2：由單位圓投影快速定位：
• 正弦（高度）：$\sin 2 > \sin 1 > \sin 3 > 0 > \sin 4$
• 餘弦（橫寬）：$\cos 1 > 0 > \cos 2 > \cos 4 > \cos 3$
• 正切（斜率）：$\tan 1 > 0 > \tan 3 > \tan 2$
SOP 2：扇形周長固定求最大面積 極值模型
步驟 1：設周長 $L = 2r + s = 2r + r\theta$，面積 $A = \frac{1}{2}rs = \frac{1}{2}r(L-2r) = -r^2 + \frac{L}{2}r$。
步驟 2：配方得 $A = -\left(r - \frac{L}{4}\right)^2 + \frac{L^2}{16}$。
• 當 $r = \frac{L}{4}$（弧長 $s = \frac{L}{2}$，圓心角 $\theta = \frac{s}{r} = 2\text{ rad}$）時，最大面積 $A_{\max} = \frac{L^2}{16}$。
SOP 3：幾何滾動與高度計算 素養幾何
步驟 1：滾動距離 $d = r\theta \implies \theta = \frac{d}{r}\text{ (rad)}$。
步驟 2：以圓心為基準建立坐標高低差：
• 若 $\theta \le \pi$：離地高度 $h = r - r\cos\theta$。
• 若 $\theta > \pi$：離地高度 $h = r + r\cos(\theta - \pi)$。
SOP 4：函數圖形平移伸縮標準化 單元 1-2
步驟 1：提出 $x$ 係數：$y = a\sin\left[b\left(x - \frac{c}{b}\right)\right] + d$。
步驟 2：判定四大要素：
• 振幅 $= |a|$，週期 $T = \frac{2\pi}{|b|}$。
• 水平平移 $= \frac{c}{b}$（正右負左），垂直平移 $= d$（正上負下）。
SOP 5：方程式實根與交點個數分析 大考焦點
步驟 1：拆解為兩函數：$y_1 = \sin x, \quad y_2 = g(x)$。
步驟 2：求直線達邊界 $y = \pm 1$ 時的臨界 $x$ 值，鎖定有效區間。
步驟 3：在有效區間內畫出零點與波峰，數出曲線穿透直線的交點數。
SOP 6：利用對稱性求多根總和 頂標速解
步驟 1：確定函數在該區間內的對稱軸 $x = x_0$。
步驟 2：若 $x_1, x_2$ 為對稱兩根，則中點 $\frac{x_1+x_2}{2} = x_0 \implies x_1+x_2 = 2x_0$。
步驟 3：多組對稱根直接將各組「$2 \times \text{對稱軸}$」相加即得總和。
SOP 7：$\sin\theta\pm\cos\theta$ 平方連鎖反應 單元 1-3
步驟 1：給定 $\sin\theta + \cos\theta = k$，平方得 $\sin 2\theta = k^2 - 1$。
步驟 2：積式 $\sin\theta\cos\theta = \frac{k^2-1}{2}$。
步驟 3：差式 $(\sin\theta-\cos\theta)^2 = 1 - \sin 2\theta = 2 - k^2$。
SOP 8：有限區間求疊合極值 滿分關鍵
步驟 1：疊合 $f(x) = \sqrt{a^2+b^2}\sin(x + \phi)$。
步驟 2：若 $x \in [\alpha, \beta]$，換元求複合角 $\theta = x+\phi \in [\alpha+\phi, \beta+\phi]$。
步驟 3：檢查 $\theta$ 範圍是否涵蓋 $\frac{\pi}{2}$ (Max) 或 $\frac{3\pi}{2}$ (Min)；若未涵蓋則代入端點。
SOP 9：二次型三角函數極值求解 二次配方
步驟 1：利用 $\cos^2 x = 1 - \sin^2 x$ 化為同名函數：$y = a(1-\sin^2 x) + b\sin x + c$。
步驟 2：令 $t = \sin x$（務必註明受限範圍 $t \in [-1, 1]$）。
步驟 3：配方求拋物線頂點，並檢查頂點是否在 $[-1, 1]$ 內。
SOP 10：正切拆角與兩線夾角 幾何解析
步驟 1：將未知角表為兩已知角之差 $\theta = \alpha - \beta$。
步驟 2：由對邊/鄰邊求 $\tan\alpha, \tan\beta$。
步驟 3：代入 $\tan\theta = \frac{\tan\alpha-\tan\beta}{1+\tan\alpha\tan\beta}$ 求出數值與角度。

1. 無單位弧度誤看成度度量
$\cos 10$ 為 $10\text{ rad} \approx 573^\circ$（第 III 象限為負），$\cos 10^\circ > 0$，切勿混淆！
2. 平移量未提 $x$ 係數
$y = \sin(2x - \frac{\pi}{3}) = \sin[2(x - \frac{\pi}{6})]$，向右平移 $\frac{\pi}{6}$（非 $\frac{\pi}{3}$）。
3. 疊合輔助角象限判斷錯誤
$-1\sin x + \sqrt{3}\cos x$ 點 $(-1, \sqrt{3})$ 在第 II 象限，輔助角為 $\frac{2\pi}{3}$（非 $\frac{\pi}{3}$）。
4. 受限區間極值只代端點
求範圍極值時，務必檢驗換元後區間是否涵蓋波峰角 $\frac{\pi}{2}$ 或波谷角 $\frac{3\pi}{2}$。
5. 兩線夾角漏加絕對值
求銳夾角公式必為 $\tan\theta = \left|\frac{m_1 - m_2}{1 + m_1 m_2}\right|$，保證正切值為正。
6. 二次配方忘記 $t$ 範圍限制
令 $t = \sin x$ 時，必須標明 $t \in [-1, 1]$，拋物線頂點若超出範圍則取端點。
7. 扇形面積公式代入度度量
$A = \frac{1}{2}r^2\theta$ 中的 $\theta$ 必須為弧度量；若給度度量須先乘 $\frac{\pi}{180}$。
8. 正切函數週期誤記為 $2\pi$
$y = \tan x$ 的週期為 $\pi$；$y = \tan bx$ 的週期為 $\frac{\pi}{|b|}$。
9. 三倍角公式係數正負寫反
$\sin 3\theta = 3\sin\theta - 4\sin^3\theta$；$\cos 3\theta = 4\cos^3\theta - 3\cos\theta$。
10. 方程式實根忘記驗證定義域
涉及 $\tan x$ 或分式時，務必剔除漸近線 $x = \frac{\pi}{2} + k\pi$ 及分母為零的無效解。
