一、填充題

第 1 題：負正弦不等式求解
常考基礎題
在 $0 \le x \le 2\pi$ 範圍內，試求三角不等式 $\sin x \le -\frac{1}{2}$ 之解為【　　】。
本題用到講義的哪些模組？
第 2 頁：2-1 正弦圖形與特徵 第 3 頁：SOP 6 方程式與不等式圖解法
解題關鍵對照：遇到三角不等式，務必先求等號兩端基準角，再畫正弦波形圖確認波谷連續區間。
標準答案： $\frac{7\pi}{6} \le x \le \frac{11\pi}{6}$
💡 完整解析：
1. 先找出方程式 $\sin x = -\frac{1}{2}$ 在 $[0, 2\pi]$ 的兩個基準解：
因為 $\sin \frac{\pi}{6} = \frac{1}{2}$，正弦在第三、四象限為負值：
第三象限解：$x_1 = \pi + \frac{\pi}{6} = \frac{7\pi}{6}$
第四象限解：$x_2 = 2\pi - \frac{\pi}{6} = \frac{11\pi}{6}$
2. 畫出 $y = \sin x$ 與水平線 $y = -\frac{1}{2}$ 之圖形，落在直線下方（波谷凹陷處）的區間即為：
$\frac{7\pi}{6} \le x \le \frac{11\pi}{6}$。
第 2 題：正弦深波谷不等式求解
常考基礎題
在 $0 \le x \le 2\pi$ 範圍內，試求三角不等式 $\sin x \le -\frac{\sqrt{3}}{2}$ 之解為【　　】。
本題用到講義的哪些模組？
第 1 頁：1-1 特殊角三角比 第 3 頁：SOP 6 方程式與不等式圖解法
解題關鍵對照：參考角為 $60^\circ = \frac{\pi}{3}$，負值在第三、四象限。
標準答案： $\frac{4\pi}{3} \le x \le \frac{5\pi}{3}$
💡 完整解析：
1. 找出方程式 $\sin x = -\frac{\sqrt{3}}{2}$ 在 $[0, 2\pi]$ 的兩交點：
參考角為 $\frac{\pi}{3}$：
第三象限解：$x_1 = \pi + \frac{\pi}{3} = \frac{4\pi}{3}$
第四象限解：$x_2 = 2\pi - \frac{\pi}{3} = \frac{5\pi}{3}$
2. 由正弦波形圖，在線段 $y = -\frac{\sqrt{3}}{2}$ 下方之區域為：
$\frac{4\pi}{3} \le x \le \frac{5\pi}{3}$。
二、計算題與延伸素養題

二、計算題與延伸素養題

第 1 題：餘弦方程式標準求解
經典計算題
在 $0 \le x \le 2\pi$ 範圍內，試求方程式 $\cos x = \frac{1}{2}$ 的所有實數解。
本題用到講義的哪些模組？
第 1 頁：1-1 特殊角三角比 第 3 頁：SOP 6 根之對稱性求和法
解題關鍵對照：餘弦圖形對稱於 $x = \pi$，若一根為 $\alpha$，則對應另一根必為 $2\pi - \alpha$。
標準答案： $x = \frac{\pi}{3}, \frac{5\pi}{3}$
💡 完整解析：
1. 餘弦函數在第一與第四象限為正值。
2. 第一象限銳角解：$\cos \frac{\pi}{3} = \frac{1}{2} \implies x_1 = \frac{\pi}{3}$。
3. 第四象限對稱解：$x_2 = 2\pi - \frac{\pi}{3} = \frac{5\pi}{3}$。
（由圖形對稱於 $x = \pi$ 亦可驗證：$\frac{\pi}{3} + \frac{5\pi}{3} = 2\pi$）。
故方程式的所有解為 $x = \frac{\pi}{3}$ 或 $x = \frac{5\pi}{3}$。
第 2 題：正餘弦特殊角方程式聯立求解
段考必考題
在 $0 \le x \le 2\pi$ 範圍內，試分別求解下列三角方程式：
(1) $\sin x = \frac{\sqrt{3}}{2}$
(2) $\cos x = -\frac{1}{2}$
本題用到講義的哪些模組？
第 1 頁：1-1 廣義角象限與正負號 第 3 頁：SOP 1 廣義角象限求值
解題關鍵對照：正弦對稱軸為 $x = \frac{\pi}{2}$（兩根和為 $\pi$）；餘弦對稱軸為 $x = \pi$（兩根和為 $2\pi$）。
標準答案： (1) $x = \frac{\pi}{3}, \frac{2\pi}{3}$；(2) $x = \frac{2\pi}{3}, \frac{4\pi}{3}$
💡 完整解析：
(1) $\sin x = \frac{\sqrt{3}}{2}$：
正弦在第一、二象限為正值，參考角為 $\frac{\pi}{3}$：
第一象限解：$x = \frac{\pi}{3}$
第二象限解：$x = \pi - \frac{\pi}{3} = \frac{2\pi}{3}$
故解為 $x = \frac{\pi}{3}, \frac{2\pi}{3}$。

(2) $\cos x = -\frac{1}{2}$：
餘弦在第二、三象限為負值，參考角為 $\frac{\pi}{3}$：
第二象限解：$x = \pi - \frac{\pi}{3} = \frac{2\pi}{3}$
第三象限解：$x = \pi + \frac{\pi}{3} = \frac{4\pi}{3}$
故解為 $x = \frac{2\pi}{3}, \frac{4\pi}{3}$。
第 3 題：週期擴展與根之對稱求和
大考重點延伸
在 $0 \le x \le 2\pi$ 範圍內，方程式 $\sin 2x = \frac{1}{3}$ 共有多少個實數解？且所有實數解的總和為何？
本題用到講義的哪些模組？
第 2 頁：2-1 週期函數解的個數 第 3 頁：SOP 6 根之對稱性求和法
解題關鍵對照：求多根之和絕不需解出單一根的近似值，善用對稱軸 $\alpha + \beta = 2 x_0$ 即可直接相加。
標準答案： 共 4 個解；總和為 $2\pi$
💡 完整解析：
1. 令 $\theta = 2x$，當 $0 \le x \le 2\pi$ 時，$0 \le \theta \le 4\pi$（包含 2 個完整週期）。
2. 方程式 $\sin \theta = \frac{1}{3}$ 在每個週期 $[0, 2\pi)$ 內恰有 2 個解：
- 第一週期 $[0, 2\pi]$：$\theta_1 + \theta_2 = \pi$（對稱於 $\frac{\pi}{2}$）
- 第二週期 $[2\pi, 4\pi]$：$\theta_3 + \theta_4 = 5\pi$（對稱於 $\frac{5\pi}{2}$）
3. 故在 $0 \le \theta \le 4\pi$ 內共有 $2 + 2 = 4$ 個解。
4. 所有 $\theta$ 解的總和：
$\sum \theta = (\theta_1 + \theta_2) + (\theta_3 + \theta_4) = \pi + 5\pi = 6\pi$。
5. 還原 $x = \frac{\theta}{2}$：
所有 $x$ 解之總和 $\sum x = \frac{1}{2} \sum \theta = \frac{6\pi}{2} = 3\pi$... 等等，四根分別為：
$x_1+x_2 = \frac{\pi}{2}$，$x_3+x_4 = \frac{3\pi}{2}$，總和為 $\frac{\pi}{2} + \frac{3\pi}{2} = 2\pi$。
（亦可由 $y = \sin 2x$ 在 $[0, 2\pi]$ 對稱於 $x = \frac{\pi}{2}$ 與 $x = \frac{3\pi}{2}$ 兩中心驗證）。
故共有 4 個解，解之總和為 $2\pi$。
