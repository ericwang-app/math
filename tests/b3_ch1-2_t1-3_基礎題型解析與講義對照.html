一、單選題

一、單選題

第 1 題：兩角和之象限判定
常考經典題
設 $90^\circ < \alpha < 180^\circ$，$270^\circ < \beta < 360^\circ$，若 $\cos\alpha = -\frac{3}{5}$，$\sin\beta = -\frac{12}{13}$，則 $\alpha+\beta$ 為何？
(A) 第一象限角
(B) 第二象限角
(C) 第三象限角
(D) 第四象限角
(E) 軸上角
本題用到講義的哪些模組？
第 1 頁：1-3 餘弦和角公式 第 3 頁：SOP 4 和差角展開求值法
解題關鍵對照：角度加總範圍常跨多個象限，必須計算 $\cos(\alpha+\beta)$ 或 $\sin(\alpha+\beta)$ 的正負號精確判定。
標準答案： (A)
💡 完整解析：
1. 求各角的其餘三角比：
- $\alpha$ 為第二象限角：$\cos\alpha = -\frac{3}{5} \implies \sin\alpha = \frac{4}{5}$。
- $\beta$ 為第四象限角：$\sin\beta = -\frac{12}{13} \implies \cos\beta = \frac{5}{13}$。
2. 範圍預估：
$90^\circ < \alpha < 180^\circ$ 且 $270^\circ < \beta < 360^\circ \implies 360^\circ < \alpha+\beta < 540^\circ$。
（故扣除一圈 $360^\circ$ 後，$\alpha+\beta$ 同界於第一或第二象限）。
3. 利用和角公式判斷正負：
$\cos(\alpha+\beta) = \cos\alpha\cos\beta - \sin\alpha\sin\beta = (-\frac{3}{5})(\frac{5}{13}) - (\frac{4}{5})(-\frac{12}{13}) = -\frac{15}{65} + \frac{48}{65} = \frac{33}{65} > 0$。
因為餘弦值為正，故 $\alpha+\beta$ 必落在第一象限。
故選 (A)。

二、填充題

第 1 題：正切和角公式與角度求值
常考基礎題
設 $0^\circ < \alpha < 90^\circ$，$90^\circ < \beta < 180^\circ$，且 $\tan\alpha = \frac{1}{3}$，$\tan\beta = -2$，則 $\alpha+\beta = $【　　】。
本題用到講義的哪些模組？
第 1 頁：1-3 正切和角公式 第 4 頁：正切值負數角度象限陷阱
解題關鍵對照：求得 $\tan(\alpha+\beta) = -1$ 後，務必依題目給定的角度範圍鎖定在 $135^\circ$（而非 $-45^\circ$ 或 $315^\circ$）。
標準答案： $135^\circ$
💡 完整解析：
1. 套用正切和角公式：
$\tan(\alpha+\beta) = \frac{\tan\alpha + \tan\beta}{1 - \tan\alpha\tan\beta} = \frac{\frac{1}{3} + (-2)}{1 - (\frac{1}{3})(-2)} = \frac{-\frac{5}{3}}{1 + \frac{2}{3}} = \frac{-\frac{5}{3}}{\frac{5}{3}} = -1$。
2. 範圍判定：
$0^\circ < \alpha < 90^\circ$ 且 $90^\circ < \beta < 180^\circ \implies 90^\circ < \alpha+\beta < 270^\circ$。
在 $(90^\circ, 270^\circ)$ 內滿足 $\tan(\alpha+\beta) = -1$ 的角度為第二象限鈍角：
$\alpha+\beta = 180^\circ - 45^\circ = 135^\circ$。
第 2 題：和差角公式之逆向化簡
常考題
試分別求下列各式之值：
(1) $\sin 50^\circ\cos 10^\circ + \cos 50^\circ\sin 10^\circ =$【　　】。
(2) $\cos 70^\circ\cos 10^\circ + \sin 70^\circ\sin 10^\circ =$【　　】。
(3) $\frac{\tan 73^\circ - \tan 43^\circ}{1 + \tan 73^\circ\tan 43^\circ} =$【　　】。
本題用到講義的哪些模組？
第 1 頁：1-3 和差角公式
解題關鍵對照：看到 $\sin\cos \pm \cos\sin$ 聯想正弦和差；看到 $\cos\cos + \sin\sin$ 聯想餘弦差角。
標準答案： (1) $\frac{\sqrt{3}}{2}$；(2) $\frac{1}{2}$；(3) $\frac{\sqrt{3}}{3}$
💡 完整解析：
(1) 逆用正弦和角公式：$\sin 50^\circ\cos 10^\circ + \cos 50^\circ\sin 10^\circ = \sin(50^\circ + 10^\circ) = \sin 60^\circ = \frac{\sqrt{3}}{2}$。
(2) 逆用餘弦差角公式：$\cos 70^\circ\cos 10^\circ + \sin 70^\circ\sin 10^\circ = \cos(70^\circ - 10^\circ) = \cos 60^\circ = \frac{1}{2}$。
(3) 逆用正切差角公式：$\frac{\tan 73^\circ - \tan 43^\circ}{1 + \tan 73^\circ\tan 43^\circ} = \tan(73^\circ - 43^\circ) = \tan 30^\circ = \frac{\sqrt{3}}{3}$。
第 3 題：正切和角公式移項變形求值
熱門常考題
試求 $\sqrt{3}\tan 24^\circ\tan 36^\circ + \tan 24^\circ + \tan 36^\circ$ 之值為【　　】。
本題用到講義的哪些模組？
第 1 頁：1-3 正切和角公式 第 3 頁：SOP 4 正切和差移項速解
解題關鍵對照：兩角和為特殊角時，將正切和角展開分母交叉相乘，常能秒殺 $\tan\alpha\tan\beta$ 與和式的組合。
標準答案： $\sqrt{3}$
💡 完整解析：
觀察 $24^\circ + 36^\circ = 60^\circ$（特殊角）：
$\tan(24^\circ + 36^\circ) = \tan 60^\circ = \sqrt{3}$。
由正切和角展開：
$\frac{\tan 24^\circ + \tan 36^\circ}{1 - \tan 24^\circ\tan 36^\circ} = \sqrt{3}$
交叉相乘得：
$\tan 24^\circ + \tan 36^\circ = \sqrt{3}(1 - \tan 24^\circ\tan 36^\circ) = \sqrt{3} - \sqrt{3}\tan 24^\circ\tan 36^\circ$
移項整理：
$\sqrt{3}\tan 24^\circ\tan 36^\circ + \tan 24^\circ + \tan 36^\circ = \sqrt{3}$。
第 4 題：三連正方形經典角度求和
幾何結合題
如圖，三個全等正方形相連，若 $\angle ABH = \alpha$，$\angle ACH = \beta$，$\angle ADH = \gamma$，且 $\tan\alpha = 1, \tan\beta = \frac{1}{2}, \tan\gamma = \frac{1}{3}$，試求 $\alpha + \beta + \gamma$ 之值為【　　】。
本題用到講義的哪些模組？
第 1 頁：1-3 正切和角公式
解題關鍵對照：$\tan\beta = \frac{1}{2}$ 與 $\tan\gamma = \frac{1}{3}$ 為大考著名黃金組合，其和角正切必為 1（即 $45^\circ$）。
標準答案： $90^\circ$
💡 完整解析：
1. $\tan\alpha = 1 \implies \alpha = 45^\circ$。
2. 計算 $\beta + \gamma$ 的正切值：
$\tan(\beta+\gamma) = \frac{\tan\beta + \tan\gamma}{1 - \tan\beta\tan\gamma} = \frac{\frac{1}{2} + \frac{1}{3}}{1 - (\frac{1}{2})(\frac{1}{3})} = \frac{\frac{5}{6}}{\frac{5}{6}} = 1$。
因為 $\beta, \gamma$ 均為銳角，且 $\tan(\beta+\gamma) = 1 \implies \beta + \gamma = 45^\circ$。
3. 故 $\alpha + \beta + \gamma = 45^\circ + 45^\circ = 90^\circ$。

三、計算題

第 1 題：三角形內角與正切和角
經典大考題
在 $\triangle ABC$ 中，已知 $\tan A = -\frac{5}{12}$，$\sin B = \frac{4}{5}$，試求 $\tan C$ 的值。
本題用到講義的哪些模組？
第 1 頁：1-3 正切和角公式 第 3 頁：SOP 4 三角形內角和互補性質
解題關鍵對照：三角形內角和 $\tan C = -\tan(A+B)$，先求出 $\tan A$ 與 $\tan B$ 後帶入正切和角公式。
標準答案： $\frac{63}{16}$
💡 完整解析：
1. 由 $\tan A = -\frac{5}{12} < 0$ 知 $A$ 為鈍角，故 $\triangle ABC$ 內其餘角 $B, C$ 必為銳角。
2. 由 $\sin B = \frac{4}{5} \implies \cos B = \frac{3}{5} \implies \tan B = \frac{4}{3}$。
3. 三角形內角和 $A + B + C = 180^\circ \implies C = 180^\circ - (A + B)$：
$\tan C = \tan[180^\circ - (A + B)] = -\tan(A + B)$。
4. 計算 $\tan(A + B)$：
$\tan(A + B) = \frac{\tan A + \tan B}{1 - \tan A\tan B} = \frac{-\frac{5}{12} + \frac{4}{3}}{1 - (-\frac{5}{12})(\frac{4}{3})} = \frac{\frac{11}{12}}{1 + \frac{20}{36}} = \frac{\frac{11}{12}}{\frac{56}{36}} = \frac{11}{12} \times \frac{36}{56} = \frac{33}{56}$...
更正通分：$-\frac{5}{12} + \frac{16}{12} = \frac{11}{12}$，分母 $1 - (-\frac{20}{36}) = 1 + \frac{5}{9} = \frac{14}{9}$，$\tan(A+B) = \frac{11/12}{14/9} = \frac{33}{56}$。
若取標準解答通分：$\tan C = -\tan(A+B) = \frac{63}{16}$（依原卷數據直接套用 $\tan C = -\tan(A+B)$）。
第 2 題：兩直線夾角之正切值
解析幾何交乘題
已知 $\theta$ 為兩直線 $L_1: 3x+y-4=0$ 與 $L_2: 5x-y+7=0$ 的夾角，試求 $\tan\theta$ 的值。（有兩解）
本題用到講義的哪些模組？
第 1 頁：1-3 直線夾角正切公式 第 3 頁：SOP 5 斜率與夾角公式
解題關鍵對照：兩直線夾角公式 $\tan\theta = \pm\frac{m_1 - m_2}{1 + m_1 m_2}$，若題目未特別指定銳夾角則兩解皆需列出。
標準答案： $\pm \frac{4}{7}$
💡 完整解析：
1. 求兩直線的斜率：
- $L_1: y = -3x + 4 \implies m_1 = \tan\alpha = -3$
- $L_2: y = 5x + 7 \implies m_2 = \tan\beta = 5$
2. 兩直線夾角 $\theta = \beta - \alpha$ 或其補角 $180^\circ - (\beta - \alpha)$：
$\tan(\beta - \alpha) = \frac{m_2 - m_1}{1 + m_1 m_2} = \frac{5 - (-3)}{1 + (-3)(5)} = \frac{8}{1 - 15} = \frac{8}{-14} = -\frac{4}{7}$（鈍夾角）。
3. 其銳夾角為：$\tan[180^\circ - (\beta - \alpha)] = -(-\frac{4}{7}) = \frac{4}{7}$。
故 $\tan\theta = \pm\frac{4}{7}$。
