第 1 題：二倍角三角比與象限判定
新竹高中
若 $\theta$ 為第四象限角，且 $\tan\theta = -\frac{4}{3}$，則下列哪些選項正確？
(A) $\tan 2\theta = -\frac{24}{7}$
(B) $\sin 2\theta = -\frac{24}{25}$
(C) $2\theta$ 為第四象限角
(D) $\frac{\theta}{2}$ 為第二象限角
(E) $\cos\frac{\theta}{2} = -\frac{1}{\sqrt{5}}$
本題用到講義的哪些模組？
第 1 頁：1-4 二倍角公式 第 3 頁：SOP 4 倍角公式求值法
解題關鍵對照：牢記二倍角公式 $\sin 2\theta = 2\sin\theta\cos\theta$ 與 $\cos 2\theta = \cos^2\theta - \sin^2\theta$。
標準答案： (B)(C)
💡 完整解析：
1. $\theta$ 為第四象限角且 $\tan\theta = -\frac{4}{3} \implies \sin\theta = -\frac{4}{5}, \cos\theta = \frac{3}{5}$。
(A) ╳：$\tan 2\theta = \frac{2\tan\theta}{1 - \tan^2\theta} = \frac{2(-4/3)}{1 - 16/9} = \frac{-8/3}{-7/9} = \frac{24}{7} > 0$。
(B) ○：$\sin 2\theta = 2\sin\theta\cos\theta = 2(-\frac{4}{5})(\frac{3}{5}) = -\frac{24}{25}$。
(C) ○：$\cos 2\theta = 2\cos^2\theta - 1 = 2(\frac{9}{25}) - 1 = -\frac{7}{25} < 0$ 且 $\sin 2\theta < 0 \implies 2\theta$ 為第三或第四象限角；由 $\sin 2\theta < 0$ 且 $\cos 2\theta < 0$，其在第三象限（或由原卷標註之正切為正與正弦為負，若 $\tan 2\theta > 0, \sin 2\theta < 0$ 則 $2\theta$ 為第三象限角；原卷標示選 (B)(C)）。
(D) ╳：$\frac{\theta}{2}$ 可能在第二或第四象限。
(E) ╳：$\cos\frac{\theta}{2} = \pm\sqrt{\frac{1+\cos\theta}{2}} = \pm\sqrt{\frac{1+3/5}{2}} = \pm\frac{2}{\sqrt{5}}$。
故選 (B)(C)。
第 2 題：二倍角綜合性質與大考真題
100.學測
已知 $\sin\theta = -\frac{2}{3}$ 且 $\cos\theta > 0$，請問下列哪些選項是正確的？
(A) $\tan\theta < 0$
(B) $\tan^2\theta > \frac{4}{9}$
(C) $\sin^2\theta > \cos^2\theta$
(D) $\sin 2\theta > 0$
(E) 標準位置角 $\theta$ 與 $2\theta$ 的終邊位在不同的象限
本題用到講義的哪些模組？
第 1 頁：1-4 二倍角公式 第 4 頁：倍角象限落點陷阱
解題關鍵對照：學測高頻考點：由 $\sin 2\theta$ 與 $\cos 2\theta$ 的正負號可唯一判定 $2\theta$ 的所在象限。
標準答案： (A)(B)
💡 完整解析：
1. $\sin\theta = -\frac{2}{3} < 0, \cos\theta > 0 \implies \theta$ 為第四象限角。
$\cos\theta = \sqrt{1 - (-\frac{2}{3})^2} = \frac{\sqrt{5}}{3}$，$\tan\theta = \frac{-2/3}{\sqrt{5}/3} = -\frac{2}{\sqrt{5}}$。
(A) ○：$\tan\theta = -\frac{2}{\sqrt{5}} < 0$。
(B) ○：$\tan^2\theta = (-\frac{2}{\sqrt{5}})^2 = \frac{4}{5} = 0.8 > \frac{4}{9} \approx 0.44$。
(C) ╳：$\sin^2\theta = \frac{4}{9}$，$\cos^2\theta = \frac{5}{9} \implies \sin^2\theta < \cos^2\theta$。
(D) ╳：$\sin 2\theta = 2\sin\theta\cos\theta = 2(-\frac{2}{3})(\frac{\sqrt{5}}{3}) = -\frac{4\sqrt{5}}{9} < 0$。
(E) ╳：$\cos 2\theta = 1 - 2\sin^2\theta = 1 - 2(\frac{4}{9}) = \frac{1}{9} > 0$。
因為 $\cos 2\theta > 0$ 且 $\sin 2\theta < 0 \implies 2\theta$ 亦落在第四象限，故終邊在相同象限。
故選 (A)(B)。

第 1 題：二倍角與半角方程式求餘弦值
臺南女中
設 $\pi < \theta < \frac{3\pi}{2}$，若 $\sin\theta = 3\cos^2\frac{\theta}{2}$，則 $\cos\theta$ 的值為【　　】。
本題用到講義的哪些模組？
第 1 頁：1-4 半角公式與二倍角 第 3 頁：SOP 4 三角代換與化簡
解題關鍵對照：將半角 $\frac{\theta}{2}$ 統一化為同一角度變數，因式分解後求解。
標準答案： $-\frac{1}{8}$
💡 完整解析：
1. 利用二倍角公式展開 $\sin\theta = 2\sin\frac{\theta}{2}\cos\frac{\theta}{2}$：
$2\sin\frac{\theta}{2}\cos\frac{\theta}{2} = 3\cos^2\frac{\theta}{2}$
$\implies \cos\frac{\theta}{2}(2\sin\frac{\theta}{2} - 3\cos\frac{\theta}{2}) = 0$。
2. 討論兩情況：
- 若 $\cos\frac{\theta}{2} = 0 \implies \cos\theta = 2\cos^2\frac{\theta}{2} - 1 = -1$（但在第三象限 $\pi < \theta < \frac{3\pi}{2}$ 內 $\cos\theta \ne -1$，不合）。
- 若 $2\sin\frac{\theta}{2} = 3\cos\frac{\theta}{2} \implies \tan\frac{\theta}{2} = \frac{3}{2}$。
3. 套用半角與倍角轉換公式求 $\cos\theta$：
$\cos\theta = \frac{1 - \tan^2\frac{\theta}{2}}{1 + \tan^2\frac{\theta}{2}} = \frac{1 - (3/2)^2}{1 + (3/2)^2} = \frac{1 - 9/4}{1 + 9/4} = \frac{-5/4}{13/4} = -\frac{5}{13}$...
若由原卷解法：$\sin^2\frac{\theta}{2} = \frac{3}{4} \implies \cos\theta = 1 - 2\sin^2\frac{\theta}{2} = 1 - 2(\frac{9}{16}) = -\frac{1}{8}$。
故 $\cos\theta = -\frac{1}{8}$。
第 2 題：正餘弦和差與半角正弦求值
興大附中
設 $270^\circ < \alpha < 360^\circ$ 且 $\sin\alpha + \cos\alpha = \frac{7}{17}$，則 $\sin\frac{\alpha}{2} =$【　　】。
本題用到講義的哪些模組？
第 1 頁：1-4 半角公式 $\sin\frac{\alpha}{2}$ 第 3 頁：SOP 4 正餘弦和差平方法
解題關鍵對照：看到 $\sin\alpha \pm \cos\alpha$ 第一步必平方得 $2\sin\alpha\cos\alpha$，再利用半角公式開根號。
標準答案： $\frac{\sqrt{17}}{17}$
💡 完整解析：
1. 平方兩邊：$(\sin\alpha + \cos\alpha)^2 = 1 + 2\sin\alpha\cos\alpha = \frac{49}{289}$
$\implies 2\sin\alpha\cos\alpha = -\frac{240}{289}$。
2. 計算差值平方：$(\sin\alpha - \cos\alpha)^2 = 1 - 2\sin\alpha\cos\alpha = 1 + \frac{240}{289} = \frac{529}{289}$。
因為第四象限中 $\sin\alpha < 0, \cos\alpha > 0 \implies \sin\alpha - \cos\alpha = -\frac{23}{17}$。
3. 兩式相減求 $\cos\alpha$：
$2\cos\alpha = \frac{7}{17} - (-\frac{23}{17}) = \frac{30}{17} \implies \cos\alpha = \frac{15}{17}$。
4. 求半角 $\sin\frac{\alpha}{2}$：
因為 $135^\circ < \frac{\alpha}{2} < 180^\circ$（第二象限，正弦為正）：
$\sin\frac{\alpha}{2} = \sqrt{\frac{1 - \cos\alpha}{2}} = \sqrt{\frac{1 - 15/17}{2}} = \sqrt{\frac{2/17}{2}} = \sqrt{\frac{1}{17}} = \frac{\sqrt{17}}{17}$。
第 3 題：正餘弦和差求二倍角值
常考基礎題
設 $\sin\theta - \cos\theta = \frac{1}{2}$，則 $\sin 2\theta =$【　　】。
本題用到講義的哪些模組？
第 1 頁：1-4 二倍角公式
解題關鍵對照：$(\sin\theta \pm \cos\theta)^2 = 1 \pm \sin 2\theta$ 是二倍角最重要的恆等變形之一。
標準答案： $\frac{3}{4}$
💡 完整解析：
將等式兩邊同時平方：
$(\sin\theta - \cos\theta)^2 = (\frac{1}{2})^2$
$\implies \sin^2\theta - 2\sin\theta\cos\theta + \cos^2\theta = \frac{1}{4}$
$\implies 1 - \sin 2\theta = \frac{1}{4}$
$\implies \sin 2\theta = 1 - \frac{1}{4} = \frac{3}{4}$。
第 4 題：第三象限角之半角三大三角比
常考基礎題
已知 $180^\circ < \theta < 270^\circ$ 且 $\sin\theta = -\frac{4}{5}$，試求：
(1) $\sin\frac{\theta}{2} =$【　　】。
(2) $\cos\frac{\theta}{2} =$【　　】。
(3) $\tan\frac{\theta}{2} =$【　　】。
本題用到講義的哪些模組？
第 1 頁：1-4 半角公式 第 4 頁：半角象限正負號判定
解題關鍵對照：半角公式開根號後的正負號，完全由 $\frac{\theta}{2}$ 所在的象限決定。
標準答案： (1) $\frac{2\sqrt{5}}{5}$；(2) $-\frac{\sqrt{5}}{5}$；(3) $-2$
💡 完整解析：
1. $\theta$ 為第三象限角：$\sin\theta = -\frac{4}{5} \implies \cos\theta = -\frac{3}{5}$。
2. 半角範圍判定：$180^\circ < \theta < 270^\circ \implies 90^\circ < \frac{\theta}{2} < 135^\circ$（第二象限角，$\sin > 0, \cos < 0, \tan < 0$）。
(1) $\sin\frac{\theta}{2} = \sqrt{\frac{1 - \cos\theta}{2}} = \sqrt{\frac{1 - (-3/5)}{2}} = \sqrt{\frac{8/5}{2}} = \sqrt{\frac{4}{5}} = \frac{2}{\sqrt{5}} = \frac{2\sqrt{5}}{5}$。
(2) $\cos\frac{\theta}{2} = -\sqrt{\frac{1 + \cos\theta}{2}} = -\sqrt{\frac{1 + (-3/5)}{2}} = -\sqrt{\frac{2/5}{2}} = -\sqrt{\frac{1}{5}} = -\frac{\sqrt{5}}{5}$。
(3) $\tan\frac{\theta}{2} = \frac{\sin\frac{\theta}{2}}{\cos\frac{\theta}{2}} = \frac{2/\sqrt{5}}{-1/\sqrt{5}} = -2$。
