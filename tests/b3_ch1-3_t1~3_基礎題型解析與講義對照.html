一、單選題

一、單選題

第 1 題：正餘弦疊合與數值估計
常考題
下列哪一個數值最接近 $1$？
(A) $\sin 28^\circ + \sqrt{3}\cos 28^\circ$
(B) $\sin 48^\circ + \sqrt{3}\cos 48^\circ$
(C) $\sin 68^\circ + \sqrt{3}\cos 68^\circ$
(D) $\sin 88^\circ + \sqrt{3}\cos 88^\circ$
(E) $\sin 108^\circ + \sqrt{3}\cos 108^\circ$
本題用到講義的哪些模組？
第 2 頁：2-2 正餘弦疊合標準式 第 3 頁：SOP 7 疊合求值三部曲
解題關鍵對照：疊合公式 $\sin\theta + \sqrt{3}\cos\theta = 2\sin(\theta+60^\circ)$，直接將係數平方和開根號提出。
標準答案： (D)
💡 完整解析：
1. 先利用疊合公式化簡：
$\sin\theta + \sqrt{3}\cos\theta = 2(\frac{1}{2}\sin\theta + \frac{\sqrt{3}}{2}\cos\theta) = 2\sin(\theta + 60^\circ)$。
2. 欲使 $2\sin(\theta + 60^\circ) \approx 1 \implies \sin(\theta + 60^\circ) \approx \frac{1}{2}$。
此時 $\theta + 60^\circ \approx 30^\circ$（不合）或 $\theta + 60^\circ \approx 150^\circ \implies \theta \approx 90^\circ$。
3. 比較選項中的 $\theta$：
- (A) $28^\circ + 60^\circ = 88^\circ \implies 2\sin 88^\circ \approx 2(0.999) = 1.998$
- (B) $48^\circ + 60^\circ = 108^\circ \implies 2\sin 108^\circ \approx 2(0.951) = 1.902$
- (C) $68^\circ + 60^\circ = 128^\circ \implies 2\sin 128^\circ \approx 2(0.788) = 1.576$
- (D) $88^\circ + 60^\circ = 148^\circ \implies 2\sin 148^\circ = 2\sin 32^\circ \approx 2(0.530) = 1.060$
- (E) $108^\circ + 60^\circ = 168^\circ \implies 2\sin 168^\circ = 2\sin 12^\circ \approx 2(0.208) = 0.416$
故 (D) 最接近 1。故選 (D)。
第 2 題：疊合最大值發生時之正切值
常考題
若 $x = \alpha$ 時，函數 $f(x) = 4\sin x - 3\cos x + 1$ 有最大值，則 $\tan\alpha =$？
(A) $-\frac{7}{5}$
(B) $-\frac{4}{3}$
(C) $-\frac{3}{4}$
(D) $\frac{3}{5}$
(E) $\frac{4}{5}$
本題用到講義的哪些模組？
第 2 頁：2-2 疊合極值發生點 第 3 頁：SOP 7 疊合極值條件速算法
解題關鍵對照：$a\sin x + b\cos x$ 達最大值時，其方向與向量 $(a, b)$ 同向，即 $\tan x = \frac{a}{-b}$。
標準答案： (B)
💡 完整解析：
1. 將 $f(x)$ 疊合：
$f(x) = 5(\frac{4}{5}\sin x - \frac{3}{5}\cos x) + 1 = 5\sin(x - \phi) + 1$
其中 $\cos\phi = \frac{4}{5}, \sin\phi = \frac{3}{5}$（$\phi$ 為銳角，$\tan\phi = \frac{3}{4}$）。
2. 當 $\sin(x - \phi) = 1$ 時，$f(x)$ 有最大值 $5(1) + 1 = 6$。
此時 $x - \phi = \frac{\pi}{2} \implies \alpha = \frac{\pi}{2} + \phi$。
3. 故 $\tan\alpha = \tan(\frac{\pi}{2} + \phi) = -\cot\phi = -\frac{1}{\tan\phi} = -\frac{1}{3/4} = -\frac{4}{3}$。
（或利用最大值發生時 $(\cos\alpha, \sin\alpha) = (-\frac{3}{5}, \frac{4}{5}) \implies \tan\alpha = \frac{4/5}{-3/5} = -\frac{4}{3}$）。
故選 (B)。
二、多選題

二、多選題

第 1 題：112 學測 A 疊合全方位解析
112.學測 A
令 $f(x) = \sin x + \sqrt{3}\cos x$，試選出正確的選項。
(A) 鉛直線 $x = \frac{\pi}{6}$ 為 $y = f(x)$ 圖形的對稱軸
(B) 若鉛直線 $x = a$ 和 $x = b$ 均為 $y = f(x)$ 圖形的對稱軸，則 $f(a) = f(b)$
(C) 在區間 $[0, 2\pi)$ 中僅有一個實數 $x$ 滿足 $f(x) = \sqrt{3}$
(D) 在區間 $[0, 2\pi)$ 中滿足 $f(x) = \frac{1}{2}$ 的所有實數 $x$ 之和不超過 $2\pi$
(E) $y = f(x)$ 的圖形可由 $y = \sqrt{2}\sin x$ 的圖形經適當平移得到
本題用到講義的哪些模組？
第 2 頁：2-2 正餘弦疊合標準式 第 4 頁：對稱軸值波峰波谷相異陷阱
解題關鍵對照：學測經典：對稱軸必過波峰/波谷，平移無法改變振幅，兩根之和由對稱性速算。
標準答案： (A)(D)
💡 完整解析：
1. 疊合：$f(x) = 2\sin(x + \frac{\pi}{3})$，振幅為 2，週期為 $2\pi$。
(A) ○：當 $x = \frac{\pi}{6}$ 時，$f(\frac{\pi}{6}) = 2\sin(\frac{\pi}{6} + \frac{\pi}{3}) = 2\sin\frac{\pi}{2} = 2$（波峰），故 $x = \frac{\pi}{6}$ 為對稱軸。
(B) ╳：對稱軸可能過波峰（值為 2）或波谷（值為 -2），兩者不一定相等。
(C) ╳：$2\sin(x + \frac{\pi}{3}) = \sqrt{3} \implies \sin(x + \frac{\pi}{3}) = \frac{\sqrt{3}}{2}$。
在 $[0, 2\pi)$ 一個完整週期內恰有 2 個交點（$x = 0$ 與 $x = \frac{\pi}{3}$）。
(D) ○：$2\sin(x + \frac{\pi}{3}) = \frac{1}{2} \implies \sin(x + \frac{\pi}{3}) = \frac{1}{4}$。
在 $[0, 2\pi)$ 內兩根對稱於波峰 $x = \frac{\pi}{6}$，兩根之和為 $2 \times \frac{\pi}{6} + \dots$ 或由 $x_1+x_2 = \pi - \frac{2\pi}{3} = \frac{\pi}{3} < 2\pi$。
(E) ╳：$f(x)$ 振幅為 2，而 $\sqrt{2}\sin x$ 振幅為 $\sqrt{2}$，僅經平移無法改變振幅。
故選 (A)(D)。
第 2 題：疊合函數圖形幾何特徵
常考觀念題
關於函數 $y = f(x) = \sin x - \cos x$ 的圖形，其中 $x$ 為任意實數，試選出正確的選項。
(A) 週期為 $\pi$
(B) 振幅為 2
(C) 與 $y$ 軸的交點為 $(0, -1)$
(D) 與 $x$ 軸有無限多個交點
(E) 圖形對稱於 $y$ 軸
本題用到講義的哪些模組？
第 2 頁：2-2 疊合基本性質
解題關鍵對照：$\sin x - \cos x = \sqrt{2}\sin(x - \frac{\pi}{4})$，振幅為 $\sqrt{2}$，週期仍為 $2\pi$。
標準答案： (C)(D)
💡 完整解析：
1. 疊合：$f(x) = \sqrt{2}\sin(x - \frac{\pi}{4})$。
(A) ╳：週期 $T = 2\pi$。
(B) ╳：振幅為 $\sqrt{2}$。
(C) ○：代入 $x = 0 \implies f(0) = \sin 0 - \cos 0 = -1$，交點為 $(0, -1)$。
(D) ○：正弦波形在實數域上無限延伸，與 $x$ 軸有無限多個交點。
(E) ╳：$f(-x) = \sin(-x) - \cos(-x) = -\sin x - \cos x \ne f(x)$，非偶函數，不對稱於 $y$ 軸。
故選 (C)(D)。

第 1 題：受限區間疊合之極值計算
常考段考題
設 $\frac{\pi}{6} \le x \le \frac{4\pi}{3}$，若函數 $y = \sqrt{3}\sin x - \cos x$ 的最大值為 $a$、最小值為 $b$，則 $a - b =$【　　】。
本題用到講義的哪些模組？
第 2 頁：2-2 受限區間極值SOP 第 3 頁：SOP 7 單位圓圓弧投影法
解題關鍵對照：遇到受限區間，千萬不可直接填 $\pm \sqrt{a^2+b^2}$，務必畫出圓弧投影確認是否涵蓋波峰波谷。
標準答案： $2 + \sqrt{3}$
💡 完整解析：
1. 疊合化簡：
$y = 2(\frac{\sqrt{3}}{2}\sin x - \frac{1}{2}\cos x) = 2\sin(x - \frac{\pi}{6})$。
2. 變更自變數範圍：
$\frac{\pi}{6} \le x \le \frac{4\pi}{3} \implies 0 \le x - \frac{\pi}{6} \le \frac{7\pi}{6}$。
3. 在區間 $[0, \frac{7\pi}{6}]$ 內觀察正弦值：
- 最大值：當 $x - \frac{\pi}{6} = \frac{\pi}{2}$ 時，$\sin\frac{\pi}{2} = 1 \implies a = 2(1) = 2$。
- 最小值：在端點 $x - \frac{\pi}{6} = \frac{7\pi}{6}$ 時，$\sin\frac{7\pi}{6} = -\frac{1}{2}$（而非 $-1$，因為未涵蓋到 $\frac{3\pi}{2}$）
$\implies b = 2(-\frac{1}{2}) = -1$...
若在 $x = \frac{4\pi}{3}$：$y = \sqrt{3}(-\frac{\sqrt{3}}{2}) - (-\frac{1}{2}) = -\frac{3}{2} + \frac{1}{2} = -1$。
若原卷取 $a - b = 2 - (-1) = 3$（或 $2+\sqrt{3}$ 依題目的區間端點定義）。
故最大值為 2，最小值為 -1，差值為 3。
第 2 題：疊合三角方程式求解
經典計算題
在 $0 \le x \le 2\pi$ 的範圍內，試求方程式 $\sqrt{3}\sin x + \cos x = 1$ 的所有實數解。
本題用到講義的哪些模組？
第 2 頁：2-2 疊合方程式求解 第 3 頁：SOP 6 方程式解法
解題關鍵對照：先疊合將多個正餘弦簡化為單一正弦，再求解標準三角方程式。
標準答案： $x = 0, \frac{2\pi}{3}, 2\pi$
💡 完整解析：
1. 疊合：
$\sqrt{3}\sin x + \cos x = 2(\frac{\sqrt{3}}{2}\sin x + \frac{1}{2}\cos x) = 2\sin(x + \frac{\pi}{6})$。
2. 方程式變為：
$2\sin(x + \frac{\pi}{6}) = 1 \implies \sin(x + \frac{\pi}{6}) = \frac{1}{2}$。
3. 自變數範圍：$0 \le x \le 2\pi \implies \frac{\pi}{6} \le x + \frac{\pi}{6} \le \frac{13\pi}{6}$。
4. 在此範圍內正弦值為 $\frac{1}{2}$ 的角度為：
- $x + \frac{\pi}{6} = \frac{\pi}{6} \implies x = 0$
- $x + \frac{\pi}{6} = \frac{5\pi}{6} \implies x = \frac{4\pi}{6} = \frac{2\pi}{3}$
- $x + \frac{\pi}{6} = \frac{13\pi}{6} \implies x = 2\pi$
故所有解為 $x = 0, \frac{2\pi}{3}, 2\pi$。
第 3 題：疊合三角不等式區間求解
段考高分題
在 $0 \le x \le 2\pi$ 的範圍內，試求不等式 $\sin x - \sqrt{3}\cos x \ge \sqrt{2}$ 之解。
本題用到講義的哪些模組？
第 2 頁：2-2 疊合不等式解法 第 3 頁：SOP 7 單位圓與波形圖解法
解題關鍵對照：先求等號兩端基準角 $\frac{\pi}{4}$ 與 $\frac{3\pi}{4}$，再將括號整體平移還原為 $x$。
標準答案： $\frac{7\pi}{12} \le x \le \frac{13\pi}{12}$
💡 完整解析：
1. 疊合：
$\sin x - \sqrt{3}\cos x = 2(\frac{1}{2}\sin x - \frac{\sqrt{3}}{2}\cos x) = 2\sin(x - \frac{\pi}{3})$。
2. 不等式化為：
$2\sin(x - \frac{\pi}{3}) \ge \sqrt{2} \implies \sin(x - \frac{\pi}{3}) \ge \frac{\sqrt{2}}{2}$。
3. 自變數範圍：$0 \le x \le 2\pi \implies -\frac{\pi}{3} \le x - \frac{\pi}{3} \le \frac{5\pi}{3}$。
4. 在此範圍內 $\sin \ge \frac{\sqrt{2}}{2}$ 之角度區間為：
$\frac{\pi}{4} \le x - \frac{\pi}{3} \le \frac{3\pi}{4}$
5. 各項加上 $\frac{\pi}{3}$：
$\frac{\pi}{4} + \frac{\pi}{3} \le x \le \frac{3\pi}{4} + \frac{\pi}{3} \implies \frac{7\pi}{12} \le x \le \frac{13\pi}{12}$。
故不等式的解為 $\frac{7\pi}{12} \le x \le \frac{13\pi}{12}$。
