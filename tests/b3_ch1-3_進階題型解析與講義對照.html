一、單一選擇題（共 8 題）

第 1 題：最接近 1 的數值估算
名校考題
下列哪一個數值最接近 $1$？
(A) $\sin 28^\circ + \sqrt{3}\cos 28^\circ$
標準答案： (D)
💡 完整解析：
由正餘弦疊合標準式：$\sin\theta + \sqrt{3}\cos\theta = 2\left(\frac{1}{2}\sin\theta + \frac{\sqrt{3}}{2}\cos\theta\right) = 2\sin(\theta + 60^\circ)$。
• (A) $2\sin(28^\circ + 60^\circ) = 2\sin 88^\circ$
• (B) $2\sin(48^\circ + 60^\circ) = 2\sin 108^\circ = 2\sin 72^\circ$
• (C) $2\sin(68^\circ + 60^\circ) = 2\sin 128^\circ = 2\sin 52^\circ$
• (D) $2\sin(88^\circ + 60^\circ) = 2\sin 148^\circ = 2\sin 32^\circ$
• (E) $2\sin(108^\circ + 60^\circ) = 2\sin 168^\circ = 2\sin 12^\circ$
因為目標值 $1 = 2\sin 30^\circ$，而在所有選項中 $2\sin 32^\circ$ 與 $2\sin 30^\circ = 1$ 最接近，故選 (D)。
第 2 題：分式和差化簡求值
臺南女中
$\frac{1}{\sin 50^\circ} + \frac{\sqrt{3}}{\cos 50^\circ}$ 的值為下列何者？
(A) $4$
標準答案： (A)
💡 完整解析：
1. 通分：$\frac{1}{\sin 50^\circ} + \frac{\sqrt{3}}{\cos 50^\circ} = \frac{\cos 50^\circ + \sqrt{3}\sin 50^\circ}{\sin 50^\circ \cos 50^\circ}$。
2. 分子正餘弦疊合：$\cos 50^\circ + \sqrt{3}\sin 50^\circ = 2\left(\frac{\sqrt{3}}{2}\sin 50^\circ + \frac{1}{2}\cos 50^\circ\right) = 2\sin(50^\circ + 30^\circ) = 2\sin 80^\circ$。
3. 分母利用二倍角公式：$\sin 50^\circ \cos 50^\circ = \frac{1}{2}\sin 100^\circ = \frac{1}{2}\sin(180^\circ - 80^\circ) = \frac{1}{2}\sin 80^\circ$。
4. 相除：$\frac{2\sin 80^\circ}{\frac{1}{2}\sin 80^\circ} = 4$。故選 (A)。
第 3 題：疊合函數求最大值
興大附中
下列選項中的值何者最大？
(A) $\sin 10^\circ + \sqrt{3}\cos 10^\circ$
標準答案： (C)
💡 完整解析：
原式疊合為 $2\sin(\theta + 60^\circ)$。
當 $\theta = 30^\circ$ 時，$2\sin(30^\circ + 60^\circ) = 2\sin 90^\circ = 2$ 達到正弦函數之最大波峰值 $2$，其餘選項皆小於 $2$。故選 (C)。
第 4 題：分式型三角函數求極值
臺中二中
設 $y = \frac{2}{3\sin\theta - 4\cos\theta + 7}$，則 $y$ 之最大值為？
(A) $\frac{1}{6}$
標準答案： (C)
💡 完整解析：
1. 分母部分疊合：$-\sqrt{3^2+(-4)^2} \le 3\sin\theta - 4\cos\theta \le \sqrt{3^2+(-4)^2} \implies -5 \le 3\sin\theta - 4\cos\theta \le 5$。
2. 加常數 7：$2 \le 3\sin\theta - 4\cos\theta + 7 \le 12$。
3. 取倒數乘 2：欲使 $y$ 最大，分母須取最小值 $2$，$y_{\max} = \frac{2}{2} = 1$。故選 (C)。
第 5 題：求最大值發生的 $x$ 自變數
臺南女中
函數 $f(x) = \sin x + \sqrt{3}\cos x + 2$ 在以下哪個 $x$ 值時有最大值？
(A) $\frac{\pi}{6}$
標準答案： (A)
💡 完整解析：
$f(x) = 2\left(\frac{1}{2}\sin x + \frac{\sqrt{3}}{2}\cos x\right) + 2 = 2\sin(x + \frac{\pi}{3}) + 2$。
當正弦達波峰時：$x + \frac{\pi}{3} = \frac{\pi}{2} \implies x = \frac{\pi}{2} - \frac{\pi}{3} = \frac{\pi}{6}$。故選 (A)。
第 6 題：最接近 $\sqrt{2}$ 的角度比較
嘉義女中
選出值最接近 $\sqrt{2}$ 的選項：
(A) $\sin 44^\circ + \sqrt{3}\cos 44^\circ$
標準答案： (D)
💡 完整解析：
所有選項均可疊合為 $2\sin(\theta + 60^\circ)$。
• (A) $2\sin 104^\circ = 2\sin 76^\circ$
• (B) $2\sin 114^\circ = 2\sin 66^\circ$
• (C) $2\sin 124^\circ = 2\sin 56^\circ$
• (D) $2\sin 134^\circ = 2\sin 46^\circ$
• (E) $2\sin 144^\circ = 2\sin 36^\circ$
目標值 $\sqrt{2} = 2 \times \frac{\sqrt{2}}{2} = 2\sin 45^\circ$，與 $2\sin 46^\circ$ 最接近。故選 (D)。
第 7 題：三角方程式解的存在性判定
臺南女中
設 $x$ 為實數，則下列哪個方程式有解？
(A) $\sin x + \cos x = 2$
標準答案： (E)
💡 完整解析：
• (A) $\sin x + \cos x = \sqrt{2}\sin(x+\frac{\pi}{4}) \in [-\sqrt{2}, \sqrt{2}]$，因 $2 > \sqrt{2}$，無解。
• (B) $\sin x\cos x = \frac{1}{2}\sin 2x \le \frac{1}{2} < 1$，無解。
• (C) 同乘 $\sin x$ 得 $\sin^2 x - \sin x + 1 = 0$，判別式 $D = (-1)^2 - 4(1)(1) = -3 < 0$，無實數解。
• (D) $2\sin x + 3\cos x \in [-\sqrt{13}, \sqrt{13}]$，因 $\sqrt{13} \approx 3.6 < 4$，無解。
• (E) $3\sin x + 4\cos x = 5\sin(x+\phi) \in [-5, 5]$，常數 $5$ 恰在值域上界，有實數解。故選 (E)。
第 8 題：受限區間疊合極值之和
師大附中
函數 $f(x) = -\sin x + \sqrt{3}\cos x + 2$ 在 $\frac{2\pi}{3} \le x \le \frac{13\pi}{12}$ 的最大值為 $M$，最小值為 $N$，求 $M + N =$？
(A) $4$
標準答案： (D)
💡 完整解析：
1. 疊合：$f(x) = 2\left(-\frac{1}{2}\sin x + \frac{\sqrt{3}}{2}\cos x\right) + 2 = 2\sin(x + \frac{2\pi}{3}) + 2$。
2. 換元：令 $\theta = x + \frac{2\pi}{3}$。因 $\frac{2\pi}{3} \le x \le \frac{13\pi}{12}$，故 $\frac{4\pi}{3} \le \theta \le \frac{7\pi}{4}$。
3. 單位圓檢驗：此區間涵蓋波谷角 $\frac{3\pi}{2}$，故 $\sin\theta$ 最小值為 $-1 \implies N = 2(-1) + 2 = 0$。
4. 端點最大值：在 $\theta = \frac{7\pi}{4}$ 時，$\sin\frac{7\pi}{4} = -\frac{\sqrt{2}}{2}$，故 $M = 2\left(-\frac{\sqrt{2}}{2}\right) + 2 = 2 - \sqrt{2}$。
5. $M + N = (2 - \sqrt{2}) + 0 = 2 - \sqrt{2}$。故選 (D)。
